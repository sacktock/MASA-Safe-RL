# Basics

These tutorials are the shortest path from a fresh checkout to a working MASA experiment.

- [First MASA Experiment](Basics/First%20MASA%20Experiment.md) shows how to preview an environment, build a MASA wrapper stack with `make_env`, inspect labels and constraint metrics, and run a tiny Q-learning smoke experiment.
- [Labels, Costs, and Infos](Basics/Labels%20Costs%20and%20Infos.md) slows down the environment loop and inspects observations, rewards, labels, costs, constraint metrics, termination, and truncation.
- [Wrapper Stack](Basics/Wrapper%20Stack.md) builds the same constrained environment with `make_env` and by manually applying each MASA wrapper.
