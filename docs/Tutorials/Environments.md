# Environments

These tutorials show how to create and adapt environments for MASA's labelling, constraint, and monitoring stack.

- [Create a New Environment](Environments/Create%20a%20New%20Environment.md) builds a tiny Gymnasium environment, adds `label_fn` and `cost_fn`, registers it with MASA, wraps it with `make_env`, and writes a short rollout test.

Runnable notebooks:

- [notebooks/tutorials/08_create_a_new_environment.ipynb](https://github.com/sacktockMASA-Safe-RL/blob/main/notebooks/tutorials/08_create_a_new_environment.ipynb)
