# Wrappers

These tutorials show how MASA wrappers reshape observations, batch environments, and maintain running normalization statistics.

- [Vectorization and Normalization](Wrappers/Vectorization%20and%20Normalization.md) demonstrates `OneHotObsWrapper`, `FlattenDictObsWrapper`, `DummyVecWrapper`, `VecWrapper`, `NormWrapper`, and `VecNormWrapper` without training a policy.
