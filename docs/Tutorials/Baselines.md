# Baselines

These tutorials show how to configure and compare MASA baselines in small, readable experiments.

For a verified list of the algorithms currently present in the codebase, start with [Algorithms Overview](../Algorithms/Overview.md).

- [Tabular Safe RL Baselines](Baselines/Tabular%20Safe%20RL%20Baselines.md) compares `q_learning`, `q_learning_lambda`, `lcrl`, `sem`, and `recreg` on one constrained tabular environment.
- [Continuous Safe RL Baselines](Baselines/Continuous%20Safe%20RL%20Baselines.md) is a stub for PPO, CPO, and PPO Lagrangian continuous-control baselines.
