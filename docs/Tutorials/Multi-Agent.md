# Multi-Agent

These tutorials show how MASA uses PettingZoo parallel environments for multi-agent safe reinforcement-learning examples.

- [Multi-Agent CMG](Multi-Agent/Multi-Agent%20CMG.md) uses repeated Chicken to explain PettingZoo parallel API dictionaries, per-agent labels, shared budgets, and constrained Markov game metrics.
