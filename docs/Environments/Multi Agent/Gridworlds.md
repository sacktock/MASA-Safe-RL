# Gridworlds

MASA includes native multi-agent tabular gridworlds using the PettingZoo `ParallelEnv` API. They expose compact feature observations, and provide default labelling and cost functions for constrained MARL.

## Available Environments

- [Capture the Flag](Gridworlds/Capture%20the%20Flag.md)
- [Clean Up](Gridworlds/Clean%20Up.md)
- [Markov Stag Hunt](Gridworlds/Markov%20Stag%20Hunt.md)
